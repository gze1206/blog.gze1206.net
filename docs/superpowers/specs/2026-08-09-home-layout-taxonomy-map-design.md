# 홈 레이아웃 · 분류 맵 디자인

관련 일감: NOR-137

## 목적

홈 화면을 미니멀한 개발자 포트폴리오로 정돈하고, 분류 관계 그래프를 `/topics`에서만 명료하게
제공한다. 글 목록과 콘텐츠 모델은 바꾸지 않는다.

## 결정

- 홈은 배경 캔버스를 주된 시각 요소로 쓰지 않는다. 얇은 그리드 또는 낮은 대비의 그라데이션만
  장식으로 남기고, 모든 콘텐츠는 읽기 가능한 표면 위에 둔다.
- 프로필 → 기술 → 프로젝트 → 최근 글 순으로 정보 위계를 고정한다.
- `/topics`만 카테고리·태그 관계 그래프를 표시한다. 홈과 다른 페이지에는 그래프를 복제하지 않는다.
- 그래프는 카테고리(큰 앵커)와 태그(작은 노드)를 좌우 두 열로 배치한 정돈된 SVG 맵이다.
- 기존 정적 카테고리·태그 링크 목록은 그래프의 폴백이자 주 탐색 수단으로 유지한다.

## 홈 구조

1. **프로필 히어로**: 이름, 한 줄 소개, 설명과 행동 링크를 하나의 얕은 표면에 배치한다.
2. **기술**: 작은 배지 나열 대신 읽기 쉬운 그룹 또는 절제된 토큰 목록으로 구성한다.
3. **프로젝트**: 동일한 테두리·반경·여백 규칙의 카드 그리드로 표시한다.
4. **최근 글**: 카드 과잉을 피하고 목록의 날짜·카테고리·제목 대비를 강화한다.

장식 배경은 `pointer-events: none`, 낮은 불투명도, `prefers-reduced-motion` 비활성 상태를
보장한다. 콘텐츠 컨테이너는 배경보다 항상 높은 쌓임 순서를 갖는다.

## 분류 맵 구조

- 노드는 기존 `buildTaxonomyGraph()` 결과만 사용한다. 새 CMS 필드, API, 런타임 fetch는 없다.
- 카테고리는 왼쪽 열에, 태그는 오른쪽 열에 둔다. 연결선은 기본 상태에서 낮은 대비로 보인다.
- 포인터 hover 또는 키보드 focus 시 선택 노드와 직접 연결된 노드·선만 강조한다.
- 노드 자체는 실제 카테고리 또는 태그 URL로 이동하는 링크다.
- 작은 화면에서는 SVG 가로 스크롤을 허용하되, 아래의 정적 탐색 목록만으로 모든 분류에 도달할 수 있다.

## 접근성 · 성능

- 그래프는 제목·설명을 가진 SVG이며, 링크의 이름은 분류명과 글 수를 함께 전달한다.
- 마우스 상호작용은 키보드 focus와 동등한 상태를 제공한다.
- 그래프가 hydration하지 않아도 정적 목록은 렌더된다. 상호작용 코드는 `/topics`에서만 지연 로드한다.
- 홈 장식은 콘텐츠를 가리지 않으며, 모션 감소 환경에서는 애니메이션을 실행하지 않는다.

## 검증

- 홈의 정적 HTML에 프로필·기술·프로젝트·최근 글의 순서와 접근 가능한 제목이 존재한다.
- 그래프 데이터와 각 링크 URL은 기존 taxonomy 단위 테스트로 유지한다.
- focus/hover 관계 강조 로직은 단위 또는 DOM 테스트로 검증한다.
- 모바일 폭과 `prefers-reduced-motion`에서 장식·그래프가 콘텐츠 접근을 방해하지 않는지 브라우저로 확인한다.

## 범위 제외

- 콘텐츠 분류 규칙, 카테고리·태그 데이터 모델 변경
- 홈 이외의 관계 그래프 노출
- 외부 시각화 라이브러리 추가 또는 서버 런타임 의존성
