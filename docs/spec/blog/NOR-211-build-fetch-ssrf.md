# NOR-211 — 블로그 빌드 중 외부 메타 조회의 SSRF 차단

- 출처: NOR-210 보안 검수(Claude·Codex, medium). 글이 자동 병합되므로 작성자가 적은 URL 을 CI 러너와 Pages 빌드가
  요청한다.

## 결정

북마크 블록의 Open Graph 조회는 `safeFetch` 로만 한다. GitHub 카드는 주소가 `api.github.com` 으로 고정이라 그대로 둔다.

- 연결하는 순간의 DNS 해석 결과를 검사한다(미리 확인하고 다른 주소로 연결하는 DNS 리바인딩을 막는다).
- 리디렉션은 자동으로 따라가지 않고 최대 3번, 매번 같은 검사를 거친다.
- http(s) 만, 사용자 정보가 든 URL 은 받지 않는다.

## 수용 기준

- **AC-1** `isPublicAddress(ip)` 는 루프백, 사설(10/8, 172.16/12, 192.168/16), 링크 로컬(169.254/16, fe80::/10), CGNAT(100.64/10), 0/8, 멀티캐스트·예약, IPv6 고유 로컬(fc00::/7), `::1`, `::`, IPv4 매핑 IPv6(`::ffff:127.0.0.1`)를 공개 주소가 아니라고 본다.
- **AC-2** `safeFetch` 는 해석 결과가 공개 주소가 아닌 호스트(예: `localhost`)에 연결하지 않고 실패한다. 서버는 요청을 받지 않는다.
- **AC-3** `safeFetch` 는 리디렉션 대상이 http(s) 가 아니거나 IP 리터럴이 공개 주소가 아니면 따라가지 않고, 4번째 리디렉션에서 실패한다.
