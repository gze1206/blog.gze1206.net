# NOR-202 — 블로그 작은 라벨과 고정폭 한글 시인성

- 출처: 사용자 보고(2026-11-15, Windows). 카테고리·태그 헤더, 포트폴리오 등 페이지 헤더의 라벨이 잘 안 보인다.

## 원인

- `--font-mono`(`ui-monospace`, `Consolas` 등)에 한글 글리프가 없다. Windows 에서는 한글이 generic `monospace` 인
  굴림체로 대체된다. "카테고리"·"태그"·"관계 지도"·"01 · 소개"·"1권" 라벨과 코드 블록의 한글 주석이 해당한다.
- eyebrow 라벨이 10~11px 이고, 영문용 넓은 자간(0.07em)이 한글에도 들어간다.

## 결정

| 항목             | 결정                                                                                           |
| ---------------- | ---------------------------------------------------------------------------------------------- |
| 고정폭 한글 대체 | `--font-mono` 의 generic `monospace` 앞에 Pretendard·Apple SD Gothic Neo·Malgun Gothic 을 둔다 |
| 한글 라벨        | 산세리프, 12px 이상, 자간 0.02em 이하. 색과 굵기는 유지한다                                    |

## 수용 기준

- **AC-1** `--font-mono` 는 generic `monospace` 보다 앞에 `Pretendard Variable` 과 `Malgun Gothic` 을 둔다.
- **AC-2** 홈·글 목록·카테고리·탐색·소개·포트폴리오·책장·글 상세에서 한글이 든 텍스트는 모두 12px 이상이다. 코드 블록, SVG 그림(관계 지도), 장식으로 숨긴 요소는 뺀다. 표지가 없는 책의 대체 표지는 옆 본문과 같은 제목·저자를 그리므로 `aria-hidden` 으로 숨긴다.
- **AC-3** 같은 페이지에서 한글이 든 라벨은 고정폭 폰트를 첫 폰트로 쓰지 않는다(코드 블록 `pre`·`code` 는 뺀다).
