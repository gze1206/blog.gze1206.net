# NOR-224 — 타이포그래피 현대화: 제목 명조 제거, Pretendard 통일

- 출처: 사용자 보고(2026-11-15). 히어로·섹션 제목의 한글 명조와 강한 음수 자간이 촌스럽게 보인다.
- 근거 조사(2026-11-15): 국내 기업 기술 블로그 9곳(토스·카카오·우아한형제들·LINE·당근·뱅크샐러드·쏘카·하이퍼커넥트·네이버 D2)은 모두 산세리프이고, 자체 서체가 아니면 대부분 Pretendard 다. 제목 굵기는 600~700, 자간은 0 이거나 아주 작은 음수다. 국내 개인 devlog 도 한 곳을 빼면 산세리프다.
- NOR-149 의 "제목만 Noto Serif KR 600" 결정을 대체한다.

## 결정

| 항목 | 결정                                                                                     |
| ---- | ---------------------------------------------------------------------------------------- |
| 서체 | 제목·본문·인용 모두 Pretendard 하나로 쓴다. 명조 웹폰트는 내려받지 않는다                |
| 굵기 | 히어로·글 제목은 800, 섹션·목록 제목은 700                                               |
| 자간 | 큰 제목은 -0.03em, 섹션 제목은 -0.02em. 사이트 어디에서도 -0.03em 보다 좁히지 않는다     |
| 성능 | 첫 화면 제목이 명조 서브셋 청크를 기다리지 않는다. 폰트 요청이 Pretendard 한 종류로 준다 |

## 수용 기준

- **AC-1** 블로그 스타일은 세리프 서체를 쓰지 않는다(`--font-serif` 토큰과 그 사용처가 없다).
- **AC-2** 블로그는 `@fontsource/noto-serif-kr` 를 가져오지도, 의존성으로 두지도 않는다.
- **AC-3** 스타일의 모든 음수 자간은 -0.03em 이상이다.
