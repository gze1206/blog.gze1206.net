# NOR-253 — 언어 전환 버튼과 번역판 댓글 통합

- 출처: 사용자 요청(2026-11-27). "언어 메뉴를 테마 메뉴랑은 완전히 다르게 이질적으로 만들어야 하는 이유가 있을까?", "언어 상관없이 같은 포스트의 댓글은 통합해서 운영하자"

## 현재

- 언어 전환은 헤더 메뉴 옆의 글자 링크("English"·"한국어")이고, 테마 전환은 오른쪽 끝의 둥근 버튼이다. 둘 다 화면 설정인데 모양과 자리가 다르다.
- 댓글 묶음 id 가 글 경로라서 영어판(`/en/blog/<slug>`)과 한국어판(`/blog/<slug>`)의 댓글이 따로 쌓인다(NOR-250).

## 결정

| 항목      | 결정                                                                                                                                                                    |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 언어 버튼 | 테마 버튼과 같은 크기·테두리의 둥근 버튼으로, 테마 버튼 바로 왼쪽에 둔다. 글자는 갈 언어의 약자(`EN`·`KO`), 접근 가능한 이름은 "English"·"한국어" 다                    |
| 댓글 묶음 | 한국어 글은 자기 경로를 쓴다(기존 댓글은 그대로다). 한국어판이 있는 영어 글은 한국어판 경로를 써서 두 언어가 한 묶음을 본다. 한국어판이 없는 영어 글은 자기 경로를 쓴다 |
| 위젯 언어 | 댓글 위젯의 화면 문구는 페이지 언어를 따른다                                                                                                                            |
| 나중 번역 | (NOR-254 에서 없앴다: 영어 글은 처음부터 `translationKey` 로 한국어판 묶음을 쓴다)                                                                                      |

## 수용 기준

- **AC-1** 헤더의 언어 전환은 테마 버튼과 같은 크기의 둥근 버튼이고 바로 옆에 있으며, 이름은 "English"(한국어 페이지)·"한국어"(영어 페이지)다.
- **AC-2** 댓글 묶음 경로는 한국어 글이면 자기 경로, 한국어판이 있는 영어 글이면 한국어판 경로, 없으면 자기 경로다. 임베드 값은 그 경로를 `pageId` 로 쓰고 위젯 언어는 페이지 언어다.
