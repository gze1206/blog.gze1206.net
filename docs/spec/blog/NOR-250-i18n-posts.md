# NOR-250 — 블로그 다국어: 글 언어와 /en 경로

- 출처: 사용자 요청(2026-11-26). 해외 게임잼처럼 개발일지를 우대하는 곳에 영어로도 보여 줄 수 있어야 한다. 영어 글 주소는 `/en/blog/<slug>` 로 정했다.
- About·포트폴리오 영어판은 NOR-251, 워크벤치는 NOR-252 에서 다룬다.

## 현재

- 사이트 전체가 한국어 하나다. `<html lang>`·`og:locale` 이 상수이고, 날짜·읽는 시간·화면 문구가 한국어로 고정돼 있다.
- 글 주소는 `/blog/<slug>` 하나이고 컬렉션 id 가 slug 라서, 같은 slug 의 두 언어판을 둘 수 없다.
- 목록·분류·RSS·검색은 모든 공개 글을 담는다.

## 결정

| 항목             | 결정                                                                                                                                                        |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 글 필드          | `lang`(`ko`·`en`, 기본 `ko`), `translationKey`(선택, slug 형식). 같은 `translationKey` 를 가진 다른 언어 글이 번역판이다                                    |
| 주소             | 한국어는 지금 주소 그대로, 영어는 `/en/blog/<slug>`, 목록 `/en/blog`, 첫 화면 `/en`, 피드 `/en/rss.xml`                                                     |
| slug             | 언어가 다르면 같은 slug 를 쓸 수 있다. 영어 글의 컬렉션 id 는 `en/<slug>` 다. 같은 언어 안에서는 지금처럼 유일해야 한다                                     |
| 페이지 언어      | 경로가 `/en` 으로 시작하면 영어 페이지다. `<html lang>`, `og:locale`, 화면 문구, 날짜 형식이 따른다                                                         |
| 한국어 화면      | 홈·블로그·카테고리·태그·시리즈·RSS·검색은 한국어 글만 담는다                                                                                                |
| 영어 글 화면     | 카테고리·태그는 링크 없이 보이고(영어 분류 페이지는 없다), 시리즈는 영어 이름이 있으면 그것을 쓰며 링크 없이 보인다. 이전·다음 편은 같은 언어 안에서 잇는다 |
| 번역판 연결      | 번역판이 있으면 글 머리에 "Read in English / 한국어로 읽기" 링크를 두고, 두 페이지 모두 `hreflang` 대안 링크를 낸다                                         |
| 헤더             | 영어 페이지는 영어 메뉴를 쓰고, 언어 전환 링크를 둔다(번역판이 있으면 그 글로, 없으면 다른 언어 첫 화면으로)                                                |
| 검색             | 사이트 검색(Pagefind)은 한국어 글만 색인한다                                                                                                                |
| 댓글             | 영어 글은 경로가 달라 댓글 묶음도 따로다. 위젯 언어는 영어다                                                                                                |
| 시리즈 영어 이름 | 시리즈에 선택 필드 `en`(`name`, `description`)을 둔다                                                                                                       |

## 수용 기준

- **AC-1** 계약의 글 스키마는 `lang`(기본 `ko`)과 `translationKey` 를 받고, 다른 언어 값이나 slug 형식이 아닌 키는 거절한다. 시리즈 스키마는 선택 필드 `en` 을 받는다.
- **AC-2** 콘텐츠 무결성 검사는 같은 언어 안의 slug 중복만 막는다. 언어가 다르면 같은 slug 를 쓸 수 있다.
- **AC-3** 언어 도우미는 경로에서 언어를 읽고(`/en` 이면 영어), 언어별 경로·날짜·읽는 시간·화면 문구를 만든다.
- **AC-4** 번역판 찾기는 같은 `translationKey` 를 가진 다른 언어의 공개 글을 돌려준다.
- **AC-5** RSS 항목 링크와 OG 대상은 글 언어에 맞는 경로를 쓴다.
- **AC-6** `/en`·`/en/blog`·`/en/rss.xml` 이 생기고, 영어 페이지의 `<html lang>` 은 `en` 이며 헤더 메뉴는 영어이고, 한국어 페이지에서 영어 첫 화면으로 가는 언어 전환 링크가 있다.
