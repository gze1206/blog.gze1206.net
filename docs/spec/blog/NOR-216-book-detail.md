# NOR-216 — 읽은 책 상세 페이지

- 출처: 사용자 요청(2026-11-15). 책 카드 안에 구절을 펼치면 좁아 읽기 어렵다. 책마다 상세 페이지를 만든다.
- 바꾸는 결정: NOR-188 "책마다 상세 페이지를 만들지 않는다". 공개 구절(NOR-215)이 생겨 읽을 거리가 있는 책이 생겼다.

## 수용 기준

- **AC-1** `bookPath(id)` 는 `/books/<인코딩한 id>` 다. 글의 `bookquote` 출처 링크는 책장에 있는 책이면 이 주소다.
- **AC-2** 공개된 책마다 `/books/<id>` 페이지가 있고, 제목·저자·역자와 그 책의 공개 구절을 모두(쪽수와 함께) 보여 준다. 구절마다 `#q-<구절 id>` 앵커가 있다.
- **AC-3** `/books` 의 책 카드는 상세 페이지로 링크하고, 카드 안에서 구절을 펼치지 않는다.
- **AC-4** 책 상세 페이지마다 OG 이미지 타깃이 있다.
