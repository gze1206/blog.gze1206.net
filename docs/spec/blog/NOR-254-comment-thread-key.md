# NOR-254 — 번역판 댓글 묶음을 처음부터 고정

- 출처: 사용자 질문(2026-11-27). "왜 저 마지막 상황 같은 예외가 있는거야"
- NOR-253 의 "나중 번역" 예외를 없앤다.

## 원인

- NOR-253 은 영어 글의 댓글 묶음을 "공개된 한국어판이 있는가" 로 정했다. 한국어판이 나중에 공개되면 묶음이 바뀌고, 그 전에 영어 글에 달린 댓글이 따로 남는다.

## 결정

| 항목            | 결정                                                                                                               |
| --------------- | ------------------------------------------------------------------------------------------------------------------ |
| 키의 뜻         | `translationKey` 는 한국어판의 slug 다. 워크벤치의 영어판 만들기는 이미 그렇게 넣는다                              |
| 영어 글 묶음    | `translationKey` 가 있으면 처음부터 `/blog/<translationKey>`(한국어판 주소)를 쓴다. 한국어판 공개 여부와 상관없다  |
| 한국어 글 묶음  | 지금처럼 자기 경로다. 기존 댓글은 그대로다                                                                         |
| 키 없는 영어 글 | 자기 경로(`/en/blog/<slug>`)다                                                                                     |
| 검사            | 한국어 글에 `translationKey` 가 있으면 자기 slug 와 같아야 한다. 다르면 빌드를 세운다(묶음이 갈라지는 것을 막는다) |

## 수용 기준

- **AC-1** 댓글 묶음 경로는 `translationKey` 가 있는 영어 글이면 `/blog/<translationKey>`, 없으면 자기 경로이고, 한국어 글은 자기 경로다. 한국어판 공개 여부에 따라 바뀌지 않는다.
- **AC-2** 콘텐츠 무결성 검사는 `translationKey` 가 자기 slug 와 다른 한국어 글을 거절한다.
