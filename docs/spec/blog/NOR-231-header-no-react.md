# NOR-231 — 머리글에서 첫 화면 React 걷어내기

- 출처: 사용자 요청(2026-11-21). PageSpeed 모바일 점수는 높지만 더 줄일 여지가 있다.

## 측정 (운영 홈, Lighthouse 12.8.2 모바일, 두 번)

| 항목            | 값                                                                       |
| --------------- | ------------------------------------------------------------------------ |
| 성능 / SEO      | 97~98 / 92                                                               |
| 미사용 JS       | `client.*.js`(React·ReactDOM) 56KB 중 28KB                               |
| 원인            | 머리글의 `SearchPalette`·`ThemeToggle` 이 모든 페이지에서 `client:load`  |
| SEO 감점        | robots.txt 의 `Content-Signal` 줄(Cloudflare 관리 robots.txt 가 붙인 것) |
| 손댈 수 없는 것 | Cloudflare 비컨의 캐시 수명(1일)과 구형 JS 10KB                          |

## 결정

| 항목        | 결정                                                                                             |
| ----------- | ------------------------------------------------------------------------------------------------ |
| 테마 전환   | Astro 컴포넌트와 프레임워크 없는 스크립트로 바꾼다. 보이는 모양·접근성 이름·저장 키는 그대로다   |
| 검색 팔레트 | 머리글에는 `/blog` 링크만 서버에서 그린다. 처음 열 때(클릭·단축키) React 팔레트를 불러와 띄운다  |
| 미리 받기   | 검색 링크에 포인터를 올리거나 포커스하면 팔레트를 미리 받기 시작한다                             |
| 실패        | 팔레트를 불러오지 못하면 링크의 기본 동작(`/blog` 로 이동)으로 돌아가고, 다음 시도에 다시 받는다 |
| robots.txt  | 저장소에서는 고치지 않는다. Cloudflare 관리 robots.txt 를 끌지는 계정 소유자가 정한다            |

## 수용 기준

- **AC-1** `lazyOnce(load)` 는 처음 부를 때만 `load` 를 실행하고, 동시에 여러 번 불러도 같은 약속을 돌려준다. `load` 가 실패하면 다음 호출에서 다시 실행한다.
- **AC-2** `nextThemePreference(resolved)` 는 지금 보이는 테마의 반대를 돌려준다.
- **AC-3** 머리글은 어느 페이지에서도 `astro-island` 를 만들지 않는다(`/topics` 의 지도는 예외). 테마 전환은 새로고침 뒤에도 유지된다.
- **AC-4** 단축키나 클릭으로 검색 팔레트가 열리고, 공개 글을 찾을 수 있다. 닫으면 검색 링크로 포커스가 돌아간다.

## 결과 (로컬 빌드 홈, Lighthouse 12.8.2 모바일, devtools 제한, 세 번 중 가운값)

| 항목              | 전(main)      | 후            |
| ----------------- | ------------- | ------------- |
| 첫 화면 JS 전송량 | 83KB          | 4KB           |
| 전체 전송량       | 450KB         | 369KB         |
| FCP / LCP         | 1.45s / 1.56s | 1.54s / 1.54s |
| TTI               | 5.48s         | 2.84s         |

- 그리기 지표는 그대로다. 첫 화면을 그리는 경로는 CSS 와 폰트가 정하고, JS 는 원래 그 경로 밖에 있었다.
- 줄어든 것은 내려받는 양과 상호작용 가능 시점이다. 모바일 회선과 저사양 기기에서 차이가 난다.
- 시뮬레이션(기본) 값은 같은 빌드에서도 FCP 가 1.2~3.5s 로 흔들려 비교에 쓰지 않았다.
