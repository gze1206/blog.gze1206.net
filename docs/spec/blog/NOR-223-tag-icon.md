# NOR-223 — 태그를 `#` 대신 태그 아이콘으로 표시

- 출처: 사용자 보고(2026-11-15). 태그 앞에 `#` 를 붙이면 `C#` 태그가 `#C#` 로 보여 어색하다.

## 결정

| 항목   | 결정                                                                                   |
| ------ | -------------------------------------------------------------------------------------- |
| 표시   | 태그 이름 앞에 태그 모양 아이콘을 둔다. 글자 `#` 는 쓰지 않는다                        |
| 구현   | CSS `::before` 의 `mask-image`(SVG data URI)로 그린다. 마크업과 접근성 트리는 그대로다 |
| 색     | `background-color: currentColor` 로 글자색을 따른다. 테마·호버 색이 함께 바뀐다        |
| 접근성 | 아이콘은 장식이다. 가상 요소의 `content` 를 비워 스크린 리더가 읽을 글자가 없다        |

## 수용 기준

- **AC-1** 글 카드(`PostCard`)·글 상세·탐색 페이지의 태그는 텍스트에 `#` 를 붙이지 않고, `tag-icon` 아이콘을 앞에 둔다.
- **AC-2** 아이콘은 `currentColor` 를 따르는 SVG 마스크이며, 가상 요소의 `content` 는 빈 문자열이다.

### 확장 (태그 전반 일관성)

- **AC-3** 태그 페이지 제목, 태그 목록(`/tags`), 책 상세의 태그도 `#` 없이 태그 아이콘을 앞에 둔다.
- **AC-4** 태그 목록의 OG 카드는 제목에 `#` 를 붙이지 않고, 제목 앞에 같은 모양의 태그 아이콘을 그린다.
