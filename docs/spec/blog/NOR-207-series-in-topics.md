# NOR-207 — 시리즈 진입점을 푸터에서 탐색으로

- 출처: 사용자 보고(2026-11-15). 시리즈가 하단 푸터 링크에만 있어 배치 의도가 드러나지 않는다.

## 결정

시리즈는 글을 묶는 **분류**다. 카테고리·태그와 같은 자리인 탐색(`/topics`)에서 찾게 한다. 탐색 페이지의
카테고리 아래에 시리즈 섹션(이름·글 수, 시리즈 페이지로 가는 링크)을 두고, 푸터의 시리즈 링크는 뺀다.
푸터에는 읽은 책과 RSS 만 남는다. `/series` 페이지는 그대로 둔다.

## 수용 기준

- **AC-1** 탐색 페이지에 "시리즈" 섹션이 있고, 글이 있는 시리즈마다 `/series/<slug>` 링크와 글 수를 보여 준다.
- **AC-2** 푸터에는 시리즈 링크가 없다.
