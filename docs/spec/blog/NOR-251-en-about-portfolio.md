# NOR-251 — 영어 About·포트폴리오와 사이트 콘텐츠 영어 필드

- 출처: 사용자 결정(2026-11-26). About·포트폴리오도 영어로 채운다. 글 다국어 구조는 NOR-250 에 있다.

## 결정

| 항목            | 결정                                                                                                                                                        |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 저장            | 항목마다 선택 필드 `en` 을 둔다. 번역할 글자만 담고, 날짜·링크·이미지 경로 같은 값은 한국어판과 함께 쓴다. 한 파일 안에 두어 두 언어가 따로 놀지 않게 한다  |
| 프로필 `en`     | `name`(선택), `headline`, `tagline`(선택), `introduction`, `about`, `linkLabels`(한국어 라벨 → 영어 라벨)                                                   |
| 경력 `en`       | `organization`(선택), `role`, `highlights`. 기간은 같은 값을 쓰고 "현재" 는 "Present" 로 보인다                                                             |
| 포트폴리오 `en` | `title`(선택), `summary`, `role`(선택), `stack`(선택), `highlights`, `media`(이미지 순서대로 `alt`·`caption`)                                               |
| 빈 영어         | `en` 이 없거나 칸이 비면 한국어 값을 쓴다. 저장소의 실제 콘텐츠는 모두 영어를 채운다                                                                        |
| 페이지          | `/en/about`·`/en/portfolio` 는 한국어 페이지 컴포넌트를 그대로 그린다. 언어는 경로에서 읽는다. 영어 About 에는 읽은 책 칸을 두지 않는다(책 기록은 한국어다) |
| 연결            | `/about` ↔ `/en/about`, `/portfolio` ↔ `/en/portfolio` 는 서로 `hreflang` 대안이고, 헤더 언어 전환이 짝 페이지로 간다. 영어 헤더에 About·Portfolio 를 둔다  |

## 수용 기준

- **AC-1** 계약의 프로필·경력·포트폴리오 스키마는 선택 필드 `en` 을 받고, 빈 문자열은 거절한다.
- **AC-2** 지역화 함수는 영어 값을 덮어쓰고 비면 한국어 값을 쓰며, 경력 기간의 "현재" 를 "Present" 로, 링크 라벨과 이미지 설명을 영어로 바꾼다.
- **AC-3** 저장소의 프로필·공개 경력·포트폴리오와 픽스처가 아닌 시리즈는 모두 영어 값을 갖는다.
- **AC-4** `/en/about`·`/en/portfolio` 는 영어로 그려지고(`lang="en"`, 영어 제목), 한국어 짝 페이지와 서로 `hreflang` 으로 이어지며, 영어 헤더에 About·Portfolio 가 있다.
