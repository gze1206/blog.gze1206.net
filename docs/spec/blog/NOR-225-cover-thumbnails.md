# NOR-225 — 책 표지 반응형 WebP 와 첫 화면 측정

- 출처: 사용자 보고(2026-11-15). 첫 화면 지표가 높게 느껴진다.

## 측정 (로컬 빌드, Lighthouse 12.8.2 모바일, 세 번 중 가운값)

| 경우                   | 홈 FCP(시뮬레이션) | 홈 FCP(devtools 제한) | 판단                                  |
| ---------------------- | ------------------ | --------------------- | ------------------------------------- |
| 현재(NOR-224 반영)     | 2.67s              | 1.6s                  | 기준                                  |
| CSS 인라인             | 3.33s              | —                     | 버림. HTML 이 116KB 로 커진다         |
| 공통 폰트 조각 preload | 1.89s              | 3.2s                  | 버림. 실제로는 CSS 와 대역폭을 다툰다 |
| 웹폰트 없음(실험)      | 1.24s              | 1.5s                  | 시뮬레이션만 크게 줄어든다(swap 덕분) |

- 웹폰트는 가변 Pretendard 가 가장 가볍다. 고정 굵기는 굵기당 113KB 라 세 굵기만 써도 가변(253KB)보다 무겁다.
- /books 의 LCP 는 표지 원본 JPEG(680×1024, 268KB)이고, 화면에는 176×265 로 보인다.

## 결정

| 항목      | 결정                                                                                               |
| --------- | -------------------------------------------------------------------------------------------------- |
| 표지      | 빌드에서 `public/assets/books` 의 표지마다 120·240·480px WebP 를 `dist/assets/books/_w/` 에 만든다 |
| 마크업    | 책장·책 상세·소개의 표지는 `srcset`·`sizes` 로 고른다. 원본보다 키우지 않는다                      |
| 개발 서버 | 썸네일이 없으므로 원본을 쓴다                                                                      |
| 실패      | 표지를 읽지 못하면 빌드를 멈춘다. 없는 썸네일을 가리키는 HTML 을 배포하지 않는다                   |

## 수용 기준

- **AC-1** `coverImage` 는 `/assets/books/<이름>.<jpg|jpeg|png|webp>` 표지에 120·240·480w WebP `srcset` 과 `sizes` 를 주고, 그 밖의 경로나 개발 모드에서는 원본 `src` 만 준다.
- **AC-2** 빌드는 표지마다 세 너비의 WebP 를 만들고, 원본보다 넓게 키우지 않는다. 읽지 못하는 표지가 있으면 실패한다.
- **AC-3** 책장·책 상세·소개 페이지의 표지는 `coverImage` 를 쓴다.
