# NOR-241 — 글 목록에서 시리즈 글의 제목 위에 시리즈 이름 표시

- 출처: 블로그 주인의 요청(2026-11-24). 시리즈 연재 글마다 제목에 "시리즈명 : " 앞머리를 붙이지 않아도, 사이트가 시리즈 소속을 보여 주는 쪽이 옳다고 판단했다.

## 결정

`series` 가 있는 글은 제목이 목록으로 나오는 모든 곳(홈·`/blog`·카테고리·태그·시리즈 페이지의 글 카드, 검색 결과)에서 제목 위에 **시리즈 라벨**(eyebrow)을 보여 준다. 라벨은 `<시리즈 이름> · <N>편` 이며 이름은 `/series/<slug>` 로 가는 링크다. 글 상세 헤더도 같은 라벨을 제목 위에 둔다(기존 메타 줄의 "시리즈 …" 표시는 이 라벨로 대체한다).

- **편 번호**는 `seriesOrder` 값이 아니라 노출 대상 목록에서의 순서이며, 상세 페이지의 `SeriesNav` 와 같은 규칙([ADR 0011](../../decisions/0011-series-navigation-derivation.md))으로 구한다. 라벨 계산은 `series-nav.ts` 의 `buildSeriesLabels` 한 곳에 둔다.
- 노출 대상이 1편뿐인 시리즈는 편 번호를 붙이지 않고 이름만 보여 준다(`buildSeriesNav` 가 1편짜리 시리즈에 블록을 만들지 않는 것과 같은 이유다).
- 카드는 전체를 링크로 감싸지 않고 제목만 링크다(NOR-16). 그래서 라벨 링크는 중첩 링크를 만들지 않는다.
- 검색 결과는 Pagefind 메타(`series`)로 라벨 문구를 받아 제목 위에 보여 준다.
- draft 글은 프로덕션 목록에서 계속 빠진다. 라벨 계산은 `getVisiblePosts()` 결과만 입력으로 받는다.

## 수용 기준

- **AC-1** 시리즈에 속한 글의 라벨은 시리즈 이름·slug 와, 노출 대상 목록에서의 편 번호(1부터)를 담는다.
- **AC-2** 시리즈에 속하지 않은 글에는 라벨이 없다.
- **AC-3** draft 인 편은 프로덕션 입력에서 빠지고, 편 번호는 그 편을 건너뛴 순서다. 같은 글의 번호는 `buildSeriesNav` 의 `position` 과 같다.
- **AC-4** 노출 대상이 1편뿐인 시리즈의 글은 이름만 있고 편 번호가 없다.
- **AC-5** 글 카드는 제목 위에 시리즈 라벨 컴포넌트를 두고, 카드 전체를 링크로 감싸지 않는다.
- **AC-6** 글 상세 헤더와 검색 결과도 같은 라벨 문구를 쓴다. 상세 헤더는 같은 컴포넌트를 제목 위에 두고, 검색 결과는 Pagefind 메타에서 받는다.
- **AC-7** (manual) 라이트·다크 테마에서 읽을 수 있고, 모바일 폭에서 줄바꿈이 깨지지 않는다.
