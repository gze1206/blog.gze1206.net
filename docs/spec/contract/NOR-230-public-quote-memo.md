# NOR-230 — 공개 구절의 메모를 함께 공개

- 출처: 사용자 결정(2026-11-15). 공개 구절에 남긴 메모는 구절과 함께 공개해도 된다. 선택지 가운데 "공개 구절이면 자동 공개" 를 골랐다.
- NOR-215 의 "메모는 내보내지 않는다"(AC-2)와 NOR-189 의 "구절 메모: 비공개" 를 대체한다. 비공개 구절의 메모와 독서 메모(`memos[]`)는 그대로 비공개다.

## 결정

| 항목      | 결정                                                                                                 |
| --------- | ---------------------------------------------------------------------------------------------------- |
| 공개      | `public: true` 이고 id 가 있는 구절의 `memo` 는 책 JSON `quotes[].memo` 로 함께 나간다               |
| 상한      | 메모는 내가 쓴 말이라 구절 누적 2,000자(저작권 상한)에 넣지 않는다. 메모 하나는 1,000자까지다        |
| 기존 메모 | 이미 쓴 공개 구절 메모도 다음 책 발행 때 나간다. 확정 전에 발행 검토 diff 에서 보인다                |
| 블로그    | 책 상세(`/books/<id>`)의 구절 아래에 메모를 "내 메모" 로 보인다. 글의 bookquote 인용에는 넣지 않는다 |
| 워크벤치  | 구절 메모 칸의 안내에 "공개 구절이면 메모도 블로그에 함께 나간다" 를 적는다                          |

## 수용 기준

- **AC-1** 계약의 `bookQuoteSchema` 는 선택 필드 `memo`(1~1,000자)를 받는다. 메모는 구절 누적 2,000자 계산에 들어가지 않는다.
- **AC-2** `toPublicBook` 은 공개 구절의 메모를 `quotes[].memo` 로 내보내고, 비공개 구절의 메모와 독서 메모는 내보내지 않는다.
- **AC-3** `planBookImport` 는 `quotes[].memo` 를 구절 메모로 되돌리고, 다시 내보내면 같다.
- **AC-4** 블로그 책 상세는 구절에 메모가 있으면 구절 아래에 보인다.
- **AC-5** 워크벤치 구절 메모 칸은 공개 구절이면 메모도 공개된다고 알린다.
