# NOR-215 — 공개 구절을 책 페이지와 워크벤치에서 보이게

- 출처: 사용자 보고·결정(2026-11-15). 공개 상태인 구절을 볼 방법이 없다 → 책 페이지 표시와 워크벤치 목록·미리보기 둘 다.
- 고치는 결정: [NOR-196](./NOR-196-books-and-bookquote.md). 그때는 "공개" 가 글 인용 허가였고 책 JSON 에 구절을 싣지 않았다.

## 결정

| 항목      | 결정                                                                                                                                                                                   |
| --------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 공개 필드 | 책 JSON 에 `quotes`(`id`·`text`·`page?`)를 더한다. 워크벤치의 `public: true` 구절만 담고, 메모·비공개 구절은 담지 않는다. 비공개 필드 `excerpts` 는 여전히 나가지 않는다(NOR-196 AC-2) |
| 상한      | 책마다 공개 구절 누적 2,000자(`QUOTE_LIMITS.bookTotal`). 넘으면 계약 스키마가 거부해 내보내기와 블로그 빌드가 모두 실패한다                                                            |
| 블로그    | `/books` 의 책 카드에 "남긴 구절 n" 을 펼쳐 볼 수 있게 둔다. 구절마다 `#<책 id>-<구절 id>` 앵커와 쪽수                                                                                 |
| 워크벤치  | 책 편집 화면에 공개 구절 목록, 누적 글자 수(n / 2,000자), 블로그에서 보일 모양(본문·쪽수·출처)을 둔다                                                                                  |
| 가져오기  | 블로그 책 JSON 의 `quotes` 는 공개 구절(`public: true`)로 되돌린다. 가져오기와 내보내기를 오가도 값이 같다(NOR-196 AC-15)                                                              |

## 수용 기준

- **AC-1** 계약의 `bookSchema` 는 `quotes` 를 받고, 같은 책의 구절 누적 글자 수가 2,000자를 넘으면 거부한다. `PUBLIC_BOOK_FIELDS` 는 `quotes` 를 담고 `excerpts` 는 담지 않는다.
- **AC-2** `toPublicBook` 은 `id` 가 있는 `public: true` 구절만 `quotes` 로 내보낸다. 메모와 비공개 구절은 내보내지 않는다.
- **AC-3** `planBookImport` 는 `quotes` 를 공개 구절로 되돌리고, 다시 `toPublicBook` 하면 같은 `quotes` 가 된다.
- **AC-4** 블로그는 책 JSON 의 구절 수만큼 구절을 보여 준다. NOR-216 부터는 책 상세 페이지(`/books/<id>`)에 보인다.
- **AC-5** 워크벤치 책 편집 화면은 공개 구절 목록과 누적 글자 수(`/ 2,000자`)를 보여 준다.
