# NOR-246 — 미리보기에서 느슨한 목록의 항목 간격

- 출처: 사용자 제보(2026-11-26). "여전히 ol에 li에 대한 줄 간격이 이상한데?"

## 원인

- 목록 안에 빈 줄이 하나라도 있으면(예: 하위 목록 뒤) Markdown 은 그 목록을 느슨한 목록으로 읽고, 상위 항목마다 내용을 `<p>` 로 감싼다. 하위 목록은 그대로 촘촘하다.
- 워크벤치 미리보기는 모든 `p` 에 위아래 여백(1rem)을 주므로 상위 항목 사이만 크게 벌어진다.
- 블로그는 본문의 직계 자식 사이에만 간격을 두므로 같은 글이 블로그에서는 고르게 보인다.

## 결정

| 항목         | 결정                                              |
| ------------ | ------------------------------------------------- |
| 항목 안 문단 | 목록 항목 안의 `p` 는 위아래 여백을 두지 않는다   |
| 항목 사이    | 블로그와 같게 이웃한 항목 사이에 0.375rem 을 둔다 |

## 수용 기준

- **AC-1** 미리보기에서 느슨한 목록의 항목 안 문단은 위아래 여백이 0 이고, 이웃한 상위 항목 사이 간격은 하위 항목 사이 간격과 같다.
