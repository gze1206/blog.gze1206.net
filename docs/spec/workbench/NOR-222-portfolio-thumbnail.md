# NOR-222 — 포트폴리오 썸네일 표시와 업로드 이미지 최적화

- 출처: 사용자 결정(2026-11-15). 포트폴리오 썸네일을 블로그 카드의 대표 이미지로 보이고, 올린 이미지의 크기·용량을 줄인다. 처리 방식은 위임받았다.
- 배경: 블로그 포트폴리오 페이지는 `thumbnail` 을 그리지 않았고, 처음 올린 썸네일은 3.5MB PNG 였다.

## 결정

| 항목 | 결정                                                                                                           |
| ---- | -------------------------------------------------------------------------------------------------------------- |
| 변환 | 워크벤치가 올린 이미지를 sharp 로 끝까지 디코딩해 검증하고, EXIF 방향을 적용한 뒤 메타데이터 없이 WebP 로 쓴다 |
| 크기 | 포트폴리오 이미지·썸네일은 가로 최대 1200px, 글 본문 이미지는 1600px. 더 작은 이미지는 키우지 않는다           |
| 표시 | 포트폴리오 카드는 썸네일이 있으면 그것을 대표 이미지로 맨 위에 그린다. 크기는 빌드할 때 파일에서 읽는다        |

## 수용 기준

- **AC-1** 포트폴리오 이미지 올리기는 가로 1200px 이하의 WebP(`.webp`)로 저장하고 그 크기를 돌려준다. 메타데이터(EXIF 등)는 남기지 않는다. 디코딩할 수 없는 파일은 거절한다.
- **AC-2** 글 본문 이미지 올리기는 가로 1600px 이하의 WebP 로 저장한다.
- **AC-3** 블로그 포트폴리오 카드는 `thumbnail` 이 있으면 그 이미지를 너비·높이와 함께 대표 이미지로 그린다. 파일이 없거나 읽지 못하면 그리지 않는다.
