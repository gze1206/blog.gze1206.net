# NOR-247 — 미리보기 너비 제한 해제

- 출처: 사용자 제보(2026-11-26). "프리뷰는 여전히 폭 제한이 있는 거 같아"

## 현재

- 미리보기 본문(`.preview`)이 최대 48rem(`max-w-3xl`)이라 넓은 화면·미리보기만 보기에서 오른쪽이 빈다. 편집기는 NOR-244 에서 제한을 없앴다.

## 결정

- 미리보기도 최대 너비를 없애 칸을 채운다. 블로그의 실제 읽기 너비는 발행 뒤 블로그에서 본다.

## 수용 기준

- **AC-1** 넓은 화면의 미리보기만 보기에서 미리보기 본문은 미리보기 칸 너비를 채운다.
