# NOR-238 — 키보드 없이 불렛과 편집기 다루기

- 출처: 사용자 요청(2026-11-24). "할일 완료 처리 등은 어떻게 해야 해? 그리고 여전히 워크벤치 조작은 데스크탑(키보드)로만 처리되는 케이스가 꽤 많네"

## 현재

- 오늘의 불렛은 항목에 초점을 두고 Alt+Enter(완료 토글), Alt+Backspace(취소), Alt+→(유형 순환)를 눌러야만 바뀐다. 화면에 누를 곳이 없어 휴대폰에서는 할 일을 끝낼 수 없다.
- 지난 미완료 검토의 할 일은 이월만 할 수 있다. 그날 끝냈거나 그만둔 일을 닫으려면 그날 화면으로 가야 하는데, 그 화면으로 가는 길도 없다.
- 편집기의 들여쓰기·내어쓰기는 Tab·Shift+Tab 뿐이다. 휴대폰 화상 키보드에는 Tab 이 없어 중첩 목록을 만들 수 없다.
- 굵게·기울임은 도구 막대 버튼이 있고, 빠른 캡처의 유형도 버튼으로 고를 수 있다. 사이드바 서랍은 바깥을 눌러 닫힌다.

## 결정

| 항목           | 결정                                                                                                               |
| -------------- | ------------------------------------------------------------------------------------------------------------------ |
| 할 일 표시     | 할 일의 기호(□·▣·⨯)를 버튼으로 만든다. 열린 할 일은 눌러 완료하고, 끝났거나 취소한 할 일은 눌러 다시 연다          |
| 그 밖의 동작   | 항목마다 "취소"(열린 할 일만)와 "유형" 버튼을 둔다. 단축키는 그대로 둔다                                             |
| 지난 할 일     | 지난 미완료 검토에도 "완료"·"취소" 버튼을 둔다. 바꾸면 그 할 일이 적힌 날짜의 기록을 고치고, 검토 목록에서 빠진다 |
| 단축키 안내    | 넓은 화면에서만 보인다                                                                                             |
| 편집기 들여쓰기 | 도구 막대에 들여쓰기·내어쓰기 버튼을 둔다                                                                         |
| 누르는 크기    | 새 버튼은 좁은 화면에서 한 변이 40px 이상이다                                                                      |

## 수용 기준

- **AC-1** 오늘의 할 일은 기호 버튼을 눌러 완료하고, 다시 눌러 연다. 열린 할 일은 "취소" 버튼으로 취소하고, 모든 불렛은 "유형" 버튼으로 유형을 바꾼다.
- **AC-2** 지난 미완료 검토의 할 일은 "완료"·"취소" 버튼으로 닫히고, 그 뒤 검토 목록에서 빠진다.
- **AC-3** 편집기 도구 막대의 들여쓰기·내어쓰기 버튼은 현재 줄을 한 단계 들이고 내민다.
- **AC-4** 좁은 화면에서 AC-1·AC-2 의 버튼은 한 변이 40px 이상이고, 단축키 안내는 보이지 않는다.
