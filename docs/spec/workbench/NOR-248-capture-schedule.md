# NOR-248 — 일일 로그의 일정을 실제 일정으로

- 출처: 사용자 제보(2026-11-26). "일정을 불릿에 추가해도 일정 취급이 안되고 완료 처리도 못하네"
- NOR-242 의 "일일 로그의 `○` 불렛은 일정과 섞지 않는다" 결정을 바꾼다. 빠른 캡처에서 "일정" 을 고르는 사람은 일정을 넣으려는 것이다.

## 현재

- 빠른 캡처의 "○ 일정" 은 그날 일지에 `○` 불렛 한 줄을 쓴다. 일정 API 에는 들어가지 않아 "이날의 일정"·일정 화면에 나오지 않는다.
- `○` 불렛은 할 일이 아니라서 완료할 수 없고, 일정에도 완료 상태가 없다.

## 결정

| 항목          | 결정                                                                                                                                                             |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 빠른 캡처     | "일정" 을 고르면 날짜(기본: 보고 있는 날)와 시각(선택) 칸이 나온다. 추가하면 일정 API 로 한 번짜리 일정을 만들고 불렛은 쓰지 않는다                              |
| 완료          | 일정은 회차마다 완료할 수 있다. 일정 파일의 `completed` 에 완료한 회차 날짜를 적는다. 반복 일정도 회차별로 따로 끝낸다                                           |
| 표시          | "이날의 일정" 과 일정 화면의 목록에 완료 버튼을 두고, 완료한 회차는 흐리게 취소선을 긋는다                                                                       |
| 기존 `○` 불렛 | 오늘의 불렛의 `○` 항목에 "일정으로" 버튼을 둔다. 누르면 그 날짜의 종일 일정을 만들고 불렛 줄을 지운다                                                            |
| 범위 편집     | "모든 일정" 은 완료 날짜도 함께 옮긴다. "이 일정만" 으로 만든 한 번짜리 일정은 완료 상태를 이어받지 않는다. "이후" 는 그날 이후의 완료 날짜를 새 일정으로 넘긴다 |

## 수용 기준

- **AC-1** 일정 파일은 `completed` 날짜 목록을 읽고 쓴다. 회차는 `completed` 여부를 함께 돌려주고, 완료를 켜고 끄면 그 날짜만 바뀐다. 범위 편집은 결정 표처럼 완료 날짜를 다룬다.
- **AC-2** API 는 회차 완료를 켜고 끈다(`POST /api/schedule/events/:id/completion`). 없는 일정은 404, 잘못된 날짜는 400 이다.
- **AC-3** API 는 일지의 `○` 불렛을 같은 날짜의 종일 일정으로 바꾸고 불렛 줄을 지운다(`POST /api/days/:date/bullets/:id/schedule`). 일정이 아닌 불렛은 400 이다.
- **AC-4** 빠른 캡처에서 "일정" 으로 시각과 함께 추가하면 "이날의 일정" 에 시각과 함께 나오고, 오늘의 불렛에는 나오지 않는다.
- **AC-5** "이날의 일정" 의 완료 버튼으로 회차를 완료하고 되돌릴 수 있고, 다시 열어도 유지된다.
- **AC-6** 오늘의 불렛의 `○` 항목은 "일정으로" 를 누르면 "이날의 일정" 으로 옮겨 간다.
