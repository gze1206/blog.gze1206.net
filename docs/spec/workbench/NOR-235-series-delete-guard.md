# NOR-235 — 글이 쓰는 시리즈는 지우지 못하게 막기

- 출처: 2026-11-23 콘텐츠 PR #87 의 CI 실패. 워크벤치에서 시리즈 `astro-guide` 를 지웠는데, 글 3편이 아직 그 시리즈를 가리켜 블로그 빌드(`assertSeriesIntegrity`)가 멈췄다.

## 현재

- 사이트 콘텐츠 검토(`createSiteReview`)는 시리즈 삭제를 아무 검사 없이 받는다.
- 블로그 빌드는 draft 를 포함한 모든 글에서 없는 시리즈를 가리키는 글이 있으면 실패한다. 그래서 잘못된 삭제는 발행 뒤 CI 에서야 드러나고, PR 이 열린 채 남는다.

## 결정

| 항목         | 결정                                                                                        |
| ------------ | ------------------------------------------------------------------------------------------- |
| 검사 시점    | 발행 검토를 만들 때 main 사본의 글을 읽어 검사한다. 발행 뒤가 아니라 검토 화면에서 거절한다 |
| 대상 글      | 블로그 빌드와 같게 draft 를 포함한 모든 글(`.md`·`.mdoc`)을 본다                            |
| 응답         | 400 과 함께, 그 시리즈를 가리키는 글 경로를 문제 목록으로 돌려준다                          |
| 읽지 못한 글 | frontmatter 를 읽지 못한 글은 건너뛴다. 그런 글은 빌드가 따로 잡는다                        |

## 수용 기준

- **AC-1** 글이 가리키는 시리즈를 지우는 검토는 400 으로 거절하고, 문제 목록에 그 글의 경로를 담는다. 발행 대기열에는 아무것도 남지 않는다.
- **AC-2** 어떤 글도 가리키지 않는 시리즈는 지금처럼 지울 수 있다.
