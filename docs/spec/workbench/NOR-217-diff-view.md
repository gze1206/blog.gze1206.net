# NOR-217 — 워크벤치 발행 검토 diff 채색과 나란히·인라인 보기

- 출처: 사용자 요청(2026-11-15). 발행 검토의 diff 를 git diff 처럼 채색하고, 나란히(side by side)와 인라인을 전환하며 보고 싶다.

## 결정

| 항목 | 결정                                                                                                               |
| ---- | ------------------------------------------------------------------------------------------------------------------ |
| 입력 | 서버가 만든 unified diff 문자열을 화면에서 줄 단위로 해석한다. diff 가 아닌 줄(예: "표지 추가/교체")은 메모로 둔다 |
| 색   | 더한 줄은 초록, 지운 줄은 빨강, 덩어리 머리(`@@`)와 파일 머리는 흐리게. 라이트·다크 모두 읽히는 반투명 배경이다    |
| 보기 | 인라인이 기본이다. 나란히 보기는 지운 줄과 더한 줄을 짝지어 왼쪽(전)·오른쪽(후)에 둔다. 고른 보기는 기억한다       |
| 범위 | 글·책·사이트 콘텐츠 발행 검토가 같은 구성 요소를 쓴다                                                              |

## 수용 기준

- **AC-1** `parseUnifiedDiff(text)` 는 줄마다 종류(`file`·`hunk`·`add`·`del`·`context`·`note`)와 전·후 줄 번호를 돌려준다.
- **AC-2** `toSideBySide(rows)` 는 덩어리 안에서 이어진 지운 줄과 더한 줄을 차례로 짝짓고, 수가 다르면 빈칸으로 채운다. 문맥 줄은 양쪽에 같이 둔다.
- **AC-3** `DiffView` 는 인라인 보기에서 줄 종류별 색(`diff-add`·`diff-del`·`diff-hunk`)과 줄 번호를 보이고, "인라인"·"나란히" 전환 버튼을 둔다. 글·책·사이트 콘텐츠 발행 검토가 이것을 쓴다.
