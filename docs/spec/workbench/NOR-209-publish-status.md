# NOR-209 — 블로그 글과 워크벤치 문서의 발행 상태 동기화

- 출처: 사용자 보고(2026-11-15). 가져온 글과 초안이 모두 public-draft 로만 보여 발행 상태가 드러나지 않고, 블로그에만 새로 생긴 글은 손으로 가져와야 한다.
- 추가 발견(PR #41): 가져온 글을 다시 발행하면 frontmatter 표기(따옴표·태그 목록 형식)가 바뀌고, `publishedAt`·`updatedAt` 의 시각이 사라져 날짜만 남는다.

## 결정

| 항목      | 결정                                                                                                                        |
| --------- | --------------------------------------------------------------------------------------------------------------------------- |
| 날짜      | 문서에 적힌 날짜 문자열(시각 포함)을 그대로 발행한다. 자르지 않는다                                                         |
| 표기 보존 | 블로그에 이미 있는 글은 그 파일의 frontmatter 를 바탕으로, 값이 바뀐 필드만 고친다. 본문 앞 빈 줄 관례도 그 파일을 따른다   |
| 상태 판정 | 새로 받은 main 에서, 지금 발행하면 나올 파일과 블로그의 파일을 비교한다. 같으면 발행됨, 다르면 블로그와 다름, 없으면 미발행 |
| 블로그만  | 작업 공간의 어떤 공개 초안 slug 와도 맞지 않는 블로그 글은 "블로그에만 있는 글" 로 알리고 가져오기로 이어 준다              |

## 수용 기준

- **AC-1** 발행 산출물의 `publishedAt`·`updatedAt` 은 문서에 적힌 값(ISO 시각 포함)을 그대로 쓴다.
- **AC-2** 블로그에 이미 있는 글을 다시 발행하면 값이 같은 frontmatter 필드는 원래 표기(따옴표·목록 형식·순서)를 유지하고, 바뀐 필드만 고치며, 없어진 필드는 지운다. 본문 앞 빈 줄 유무도 원래 파일을 따른다. 내용이 같으면 diff 가 비어 있다.
- **AC-3** `GET /api/publish/status` 는 공개 초안마다 `published`·`differs`·`unpublished`·`invalid`(발행 검사 실패) 중 하나를, 그리고 블로그에만 있는 글(slug·제목·경로)을 돌려준다.
- **AC-4** 문서 목록은 공개 초안에 발행 상태(발행됨·블로그와 다름·미발행·검사 실패)를 표시하고, 블로그에만 있는 글이 있으면 그 수를 알리며 가져오기를 열 수 있다.
