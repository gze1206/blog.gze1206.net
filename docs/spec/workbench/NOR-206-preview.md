# NOR-206 — 워크벤치 문서 미리보기 (1단계) 와 WYSIWYG (2단계)

- 출처: 사용자 보고(2026-11-15). 편집기가 WYSIWYG 이 아니고, 렌더한 모습을 미리 볼 방법도 없다.
- 1단계(이 명세의 AC-1~5): 렌더 미리보기. 2단계(WYSIWYG)는 Markdoc 태그·frontmatter 를 보존하는 편집기를 따로 붙인다.

## 결정

| 항목 | 결정                                                                                                                                   |
| ---- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 렌더 | 서버에서 Markdoc 으로 렌더한다. 블로그와 같은 문법(원시 HTML 없음)이고, `bookquote` 는 작업 공간의 책 문서로 실제 구절과 출처를 펼친다 |
| 태그 | 콜아웃·북마크·GitHub·수식·영상·그림 같은 블로그 태그는 비슷한 모양(링크·자리 표시)으로 그린다. 정확한 모양은 발행 뒤 블로그에서 본다   |
| 안전 | 링크·이미지 주소는 http(s)·mailto·상대 경로만 둔다. 텍스트는 Markdoc 이 이스케이프한다                                                 |
| 화면 | 편집기 머리에 편집·나란히·미리보기 전환. 저장하지 않은 내용도 미리 본다(입력이 멈추면 다시 그린다)                                     |

## 수용 기준

- **AC-1** `renderPreview(source)` 는 frontmatter 를 빼고 본문을 HTML 로 렌더한다. 원시 HTML 은 글자로 남고, `javascript:` 같은 주소는 링크가 되지 않는다.
- **AC-2** `bookquote` 는 책 문서의 공개 구절을 `<figure class="bookquote">` 와 출처(저자, 『제목』, 쪽수)로 펼친다. 펼칠 수 없으면 오류가 아니라 경고를 돌려준다.
- **AC-3** 블로그 태그(callout·bookmark·github·math·mathblock·youtube·video·figure)는 오류 없이 그린다.
- **AC-4** `POST /api/preview` 는 저장하지 않은 원본을 받아 `{ html, warnings }` 를 돌려준다.
- **AC-5** 문서 편집기는 편집·나란히·미리보기 전환을 두고, 미리보기에서 렌더 결과를 보여 준다.
