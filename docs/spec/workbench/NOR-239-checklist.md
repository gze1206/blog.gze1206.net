# NOR-239 — Markdown 체크리스트

- 출처: 사용자 요청(2026-11-24). "마크다운 편집할 때 체크리스트 등에 대한 처리도 필요해보이고"

## 현재

- 편집기 파서는 GFM 작업 목록(`- [ ] 할 일`)을 `Task`·`TaskMarker` 로 읽지만, 라이브 프리뷰는 `[ ]` 를 글자 그대로 보인다. 누를 수 없고, 끝낸 항목도 구별되지 않는다.
- 도구 막대에 체크리스트 버튼이 없다. 휴대폰에서는 `- [ ] ` 를 손으로 쳐야 한다.
- 블로그와 워크벤치 미리보기는 Markdoc 으로 렌더한다. Markdoc 은 작업 목록을 모르므로 `[ ] 할 일` 이 글자로 나온다.

## 결정

| 항목          | 결정                                                                                                                                       |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 편집기 표시   | 커서가 없는 줄의 `[ ]`·`[x]` 를 체크박스로 그린다. 커서가 있는 줄은 다른 표시 문자처럼 원본을 보인다                                      |
| 누르기        | 체크박스를 누르면 원본의 `[ ]` 와 `[x]` 를 바꾼다. 누르는 동안 커서를 옮기지 않는다(옮기면 그 줄이 원본으로 바뀌어 체크박스가 사라진다) |
| 끝낸 항목     | 줄을 흐리게 하고 취소선을 긋는다                                                                                                           |
| 도구 막대     | "체크리스트" 버튼이 줄마다 `- [ ] ` 를 붙이거나 뗀다                                                                                       |
| 렌더          | 계약에 Markdoc `item` 노드를 두고 블로그와 워크벤치 미리보기가 같이 쓴다. 공개 글의 체크박스는 누를 수 없다(`disabled`)                   |
| 대상 표기     | `[ ]`, `[x]`, `[X]` 뒤에 공백이 오는 항목만 작업으로 본다. 느슨한 목록(항목 사이 빈 줄)도 같다                                             |

## 수용 기준

- **AC-1** 라이브 프리뷰는 커서가 없는 줄의 작업 표시를 체크박스 장식으로 바꾸고, 끝낸 작업 줄에 완료 클래스를 붙인다. 커서가 있는 줄은 원본을 보인다.
- **AC-2** `toggleTask` 는 주어진 위치의 작업 표시를 `[ ]` ↔ `[x]` 로 바꾸고(`[X]` 는 `[ ]` 로), 작업이 아닌 위치에서는 아무것도 바꾸지 않는다.
- **AC-3** 편집기에서 체크박스를 누르면 원본이 바뀌고 커서는 그 줄로 옮겨지지 않는다. 도구 막대의 "체크리스트" 버튼은 현재 줄에 `- [ ] ` 를 붙인다.
- **AC-4** 계약의 Markdoc `item` 노드는 작업 항목을 `class="task-list-item"` 인 `li` 와 `disabled` 체크박스로 렌더하고, 끝낸 항목은 `checked` 를 붙인다. 작업이 아닌 항목은 그대로 둔다.
- **AC-5** 블로그와 워크벤치 미리보기는 계약의 `item` 노드를 쓴다.
