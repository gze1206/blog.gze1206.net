# NOR-252 — 워크벤치 다국어: 초안 언어·영어판 만들기·사이트 콘텐츠 영어 필드

- 출처: 사용자 요청(2026-11-26). 블로그가 영어 글(NOR-250)과 사이트 콘텐츠 영어판(NOR-251)을 받게 됐으니, 워크벤치에서 그것을 쓰고 발행할 수 있어야 한다.

## 결정

| 항목                | 결정                                                                                                                                                                                                                                                                                                                                      |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 초안 필드           | 공개 초안은 `lang`(ko·en)과 `translationKey` 를 받는다. 없으면 한국어다                                                                                                                                                                                                                                                                   |
| 발행 자리           | 영어 글은 `posts/en/<slug>.mdoc` 에, 브랜치는 `content/en-<slug>` 로 낸다. 이미지는 언어와 상관없이 `assets/posts/<slug>/` 를 같이 쓴다                                                                                                                                                                                                   |
| 발행 상태           | 초안과 블로그 글을 언어와 slug 로 견준다                                                                                                                                                                                                                                                                                                  |
| 영어판 만들기       | 한국어 공개 초안에서 영어판 초안을 만든다. 메타와 본문을 복사하고 제목 앞에 `[EN] ` 을 붙이며(번역할 거리임을 보이고, 원본과 이름이 겹치지 않게) `lang: en`, `draft: true`(번역 전 공개 방지), `translationKey`(원본 값, 없으면 slug)를 넣는다. 원본에 키가 없으면 원본에도 적는다. 자리는 `drafts/<slug>.en.md` 이고, 이미 있으면 409 다 |
| 사이트 콘텐츠 폼    | 프로필·경력·포트폴리오·시리즈 폼에 "영어 · …" 칸을 둔다. 값은 `en` 안에 쓰고, 영어 칸을 모두 비우면 `en` 을 지운다                                                                                                                                                                                                                        |
| 블로그에서 가져오기 | 지금처럼 한국어 글만 가져온다. 영어 글 가져오기는 영어 글이 생긴 뒤 다룬다                                                                                                                                                                                                                                                                |

## 수용 기준

- **AC-1** 공개 초안 문서는 `lang`·`translationKey` 를 받고, 영어 초안을 변환하면 공개 frontmatter 에 `lang: en` 과 `translationKey` 가 들어간다. 한국어 초안은 `lang` 을 쓰지 않는다.
- **AC-2** 영어 초안의 발행 검토는 대상 경로가 `posts/en/<slug>.mdoc` 이고 브랜치가 `content/en-<slug>` 다.
- **AC-3** 영어판 계획은 한국어 공개 초안에서 영어 초안 원문과 자리(`drafts/<slug>.en.md`)를 만들고, 원본에 키가 없으면 원본에 넣을 원문도 돌려준다. 공개 초안이 아니거나 이미 영어면 거절한다.
- **AC-4** `POST /api/documents/:id/translation` 은 영어 초안을 만들어 201 로 돌려주고, 이미 있으면 409 다.
- **AC-5** 편집기에서 한국어 공개 초안을 열면 "영어판 만들기" 가 있고, 누르면 새 영어 초안이 열린다.
- **AC-6** 사이트 콘텐츠 폼의 영어 칸은 `en` 안의 값을 읽고 쓰며, 영어 칸을 모두 비우면 `en` 을 지운다.
