# NOR-204 — 책 편집에서 표지 바꾸기와 역자 입력

- 출처: 사용자 보고(2026-11-15). ISBN 으로 표지를 불러오거나 올리는 기능이 안 보이고, 역자를 입력할 방법이 없다.

## 현재

- ISBN 조회와 표지 업로드는 **책 등록** 대화상자에만 있다. 등록한 뒤 여는 책 편집 화면에서는 표지를 바꿀 수 없다.
  블로그에서 가져온 책처럼 등록 대화상자를 거치지 않은 책은 표지를 붙일 길이 없다.
- 역자(`translators`)는 계약·서버 API 에 있지만 등록·편집 화면에 입력 칸이 없다.

## 결정

표지는 다른 필드와 따로 바꾼다(`PUT /api/books/:id` 는 표지를 건드리지 않는다는 기존 규칙을 지킨다).
`PUT /api/books/:id/cover` 가 세 가지를 받는다: 올려 둔 파일 경로, 조회한 표지 주소(서버가 받아 저장), 지우기.

## 수용 기준

- **AC-1** `PUT /api/books/:id/cover` 에 `{ cover: 'assets/books/<파일>' }` 를 보내면 그 표지로 바꾸고 나머지 필드와 본문은 그대로 둔다. 작업 공간 밖을 가리키는 경로는 400 이다.
- **AC-2** `{ coverUrl, coverSource }` 를 보내면 서버가 표지를 받아 `assets/books/` 에 두고 `cover`·`coverSource` 를 바꾼다. 받지 못하면 502 이고 문서는 그대로다.
- **AC-3** `{ remove: true }` 를 보내면 `cover`·`coverSource` 를 지운다.
- **AC-4** 책 편집 화면은 역자 입력 칸(쉼표 구분)과 표지 바꾸기 동작(파일로 바꾸기, ISBN 으로 찾기, 표지 지우기)을 보여 준다.
- **AC-5** 책 등록 대화상자는 역자 입력 칸을 보여 준다.
