# NOR-245 — 목록·체크리스트에서 Enter 로 항목 이어쓰기

- 출처: 사용자 요청(2026-11-26). "목록이나 체크리스트면 개행했을 때 기본적으로 그냥 빈 줄이 아니라 목록/체크리스트 속성이 유지되게끔 하자"
- NOR-206 AC-8 의 "목록 자동 이어쓰기 없음" 결정을 바꾼다. 손으로 `- ` 를 매번 치는 비용이 원본을 그대로 두는 이점보다 크다(특히 휴대폰).

## 결정

| 상황                          | Enter 를 누르면                               |
| ----------------------------- | --------------------------------------------- |
| 글이 있는 목록 항목           | 다음 줄에 같은 들여쓰기와 표시(`- `)를 붙인다 |
| 체크리스트 항목(끝낸 것 포함) | 다음 줄에 빈 체크박스(`- [ ] `)를 붙인다      |
| 번호 목록                     | 다음 번호를 붙인다                            |
| 글이 없는 항목                | 표시를 지우고 목록을 끝낸다                   |
| 목록이 아닌 줄                | 지금처럼 줄만 바꾼다                          |

- 표시만 있는 줄 바로 뒤에서 Backspace 를 누르면 표시를 한 번에 지운다. 두 번째 이후 항목은 위 항목에 딸린 문단으로 남아 들여쓰기가 남을 수 있다(Markdown 규칙). 목록을 완전히 끝낼 때는 빈 항목에서 Enter 를 누른다.
- 빈 줄로 떨어진 항목이 같은 목록으로 읽혀도, 이어 쓸 때는 빈 줄을 넣지 않고 바로 다음 줄에 붙인다.
- CodeMirror Markdown 의 `insertNewlineContinueMarkup`·`deleteMarkupBackward` 를 쓴다.

## 수용 기준

- **AC-1** 목록 항목 끝에서 Enter 를 누르면 다음 줄이 `- ` 로, 체크리스트 항목이면 `- [ ] ` 로, 번호 목록이면 다음 번호로 시작한다.
- **AC-2** 글이 없는 목록 항목에서 Enter 를 누르면 표시가 지워지고, 목록이 아닌 줄에서는 줄만 바뀐다.
- **AC-3** 표시만 있는 줄 끝에서 Backspace 를 누르면 표시가 지워진다.
