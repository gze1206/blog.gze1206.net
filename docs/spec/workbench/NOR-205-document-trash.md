# NOR-205 — 워크벤치 문서 삭제(휴지통)

- 출처: 사용자 보고(2026-11-15). 포스트 등 문서를 지울 방법이 없다.

## 결정

| 항목   | 결정                                                                                                                                                            |
| ------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 삭제   | 바로 지우지 않고 작업 공간의 `.workbench/trash/` 로 옮긴다. 이 디렉터리는 git 백업에서 빠지고(`.workbench/` 무시), 문서 목록도 점으로 시작하는 곳을 읽지 않는다 |
| 되돌림 | 휴지통에서 원래 자리로 복원한다. 그 자리에 다른 문서가 있으면 거절한다(덮어쓰지 않는다)                                                                         |
| 비움   | 휴지통에서 하나씩 영구 삭제한다. 지운 문서는 git 이력과 백업 bundle 에는 남는다                                                                                 |
| 범위   | 작업 공간 문서만 지운다. 이미 공개 블로그로 발행한 글은 블로그에서 따로 내려야 한다(삭제 확인 문구에 적는다)                                                    |

## 수용 기준

- **AC-1** `trashDocument(relativePath)` 는 문서를 휴지통으로 옮긴다. 문서 목록에서 빠지고 `listTrash()` 에 원래 경로·제목·지운 시각과 함께 나온다.
- **AC-2** `restoreTrash(id)` 는 원래 자리로 되돌린다. 그 자리에 문서가 있으면 실패하고 두 파일 모두 그대로다.
- **AC-3** `purgeTrash(id)` 는 휴지통에서 영구히 지운다. 휴지통 밖을 가리키는 id 는 거절한다.
- **AC-4** API: `DELETE /api/documents/:id`, `GET /api/trash`, `POST /api/trash/:id/restore`(충돌 409), `DELETE /api/trash/:id`.
- **AC-5** 편집 화면(문서·책)에 "삭제" 버튼이 있고, 사이드바에 휴지통 목록(복원·영구 삭제)이 있다. 삭제하면 목록에서 빠지고 휴지통에 나타나며, 복원하면 돌아온다.
