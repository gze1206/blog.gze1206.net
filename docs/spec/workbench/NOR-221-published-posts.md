# NOR-221 — 발행된 글을 워크벤치에서 발행된 글로 보이기

- 출처: 사용자 보고(2026-11-15). 블로그에 발행된 글도 워크벤치에서 `public-draft` 로만 보인다.
- 결정(사용자): 파일의 `kind` 는 그대로 두고, 블로그와 비교한 발행 상태(NOR-209)로 나눠 보인다. 블로그가 원본이라 파일과 블로그가 어긋날 일이 없고, 기존 문서를 옮길 필요가 없다.

## 수용 기준

- **AC-1** 문서 목록은 종류를 사람이 읽는 이름(빠른 메모·비공개 글·주간 회고·책 등)으로 보인다. 공개 초안은 발행 상태가 발행됨·블로그와 다름이면 "발행된 글", 미발행·검사 실패면 "공개 초안", 아직 모르면 "공개 글" 이다.
- **AC-2** 문서 목록은 문서 유형별(블로그 글·비공개 글·메모·회고·일지·책)로 묶고, 블로그 글은 카테고리별로 한 번 더 묶는다(사용자 요청). 묶음마다 수를 보이고 접고 펼 수 있으며, 카테고리가 없는 글은 "카테고리 없음" 에 둔다. 빈 묶음은 보이지 않는다.
- **AC-3** 편집기 머리는 발행된 글이면 "블로그에 발행된 글" 과 상태를 보이고, 발행 버튼은 "다시 발행 검토" 다.
