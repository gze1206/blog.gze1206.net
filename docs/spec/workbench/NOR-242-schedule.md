# NOR-242 — 일정: 날짜·시각·반복 일정 모델과 API

- 출처: 사용자 요청(2026-11-25). "일정은 오늘이 아니라 특정 어느 날짜에 일어나는 거나 반복되는 일정, 특정 일시에 있는 일정 등이 있을텐데 그것들을 다룰 방법이 지금 전무해. 일반적인 일정 관리 앱 수준으로는 지원하는 게 어렵지않을텐데 보강해두자"
- 화면은 NOR-243 에서 만든다. 이 명세는 저장 모델, 반복 전개, 고치기·지우기 범위, API 를 정한다.

## 현재

- 일정은 일일 로그의 불렛(`○`) 뿐이다. 그날 적은 기록이라 미래 날짜, 시각, 반복을 담을 곳이 없다.

## 결정

| 항목        | 결정                                                                                                                                                                                                                                                                                                                                                        |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 저장        | 작업 공간 `schedule/<ULID>.md` 에 일정 하나씩 둔다. YAML frontmatter 가 일정이고 본문이 메모다. 문서 목록에는 나오지 않는다                                                                                                                                                                                                                                 |
| 불렛과 관계 | 일일 로그의 `○` 불렛은 그날의 기록으로 그대로 둔다. 일정과 섞지 않는다                                                                                                                                                                                                                                                                                      |
| 시각        | 앱 시간대(`APP_TIME_ZONE`)의 벽시계 값(`YYYY-MM-DD`, `HH:mm`)으로 둔다. 시간대 변환은 하지 않는다                                                                                                                                                                                                                                                           |
| 종일·시각   | `time` 이 없으면 종일이다. `endTime` 은 `time` 이 있을 때만 쓰고 `time` 보다 늦어야 한다                                                                                                                                                                                                                                                                    |
| 여러 날     | `endDate` 로 여러 날에 걸친 일정을 둔다(`date` 이상). 반복 일정의 각 회차도 같은 길이로 걸친다                                                                                                                                                                                                                                                              |
| 반복        | `repeat.freq` 는 `daily`·`weekly`·`monthly`·`yearly`, `interval` 은 1 이상. 주간은 `weekdays`(없으면 시작 요일), 월간은 시작일의 날짜(그 달에 없으면 건너뜀), 연간은 같은 월·일(2월 29일은 윤년에만)                                                                                                                                                        |
| 끝          | `repeat.until`(그날 포함) 또는 `repeat.count`(회차 수) 중 하나. 없으면 끝없이 반복한다                                                                                                                                                                                                                                                                      |
| 예외        | `exceptions` 에 적은 날짜의 회차는 건너뛴다                                                                                                                                                                                                                                                                                                                 |
| 고치기 범위 | 반복 일정은 "이 일정만"·"이후 모든 일정"·"모든 일정" 으로 고친다. "이 일정만" 은 그 회차를 예외로 두고 한 번짜리 일정을 새로 만든다. "이후" 는 원래 일정을 전날에서 끝내고 그날부터 새 반복을 만든다(횟수로 끝나면 남은 횟수를 넘긴다). "모든 일정" 은 같은 id 로 고치고, 회차 날짜를 옮긴 만큼 시작일을 옮긴다. 고친 값의 날짜는 화면에 보인 회차의 날짜다 |
| 지우기 범위 | 같은 세 범위. "이 일정만" 은 예외 추가, "이후" 는 전날에서 끝냄, "모든 일정" 은 파일을 휴지통 없이 지운다(일정은 문서가 아니다)                                                                                                                                                                                                                             |
| 조회        | 기간(`from`~`to`, 최대 400일)을 받아 회차를 펼쳐 날짜·시각 순으로 돌려준다. 여러 날에 걸친 회차는 기간과 겹치면 나온다                                                                                                                                                                                                                                      |
| 알림        | 이번에는 넣지 않는다. 푸시 서버가 필요해 따로 다룬다                                                                                                                                                                                                                                                                                                        |

## 수용 기준

- **AC-1** 일정 파일을 읽고 쓰면 같은 값이 된다. 제목이 비었거나, 날짜·시각이 형식에 맞지 않거나, `endTime` 이 `time` 보다 이르거나 `time` 없이 있거나, `endDate` 가 `date` 보다 이르거나, `until` 과 `count` 가 함께 있으면 오류다.
- **AC-2** 반복 전개는 매일·매주(요일 지정)·매월·매년과 `interval` 을 따르고, 31일·2월 29일처럼 없는 날은 건너뛰며, `until`·`count`·`exceptions` 를 지킨다.
- **AC-3** 여러 날에 걸친 일정의 회차는 조회 기간과 겹치면 나오고, 회차마다 시작·끝 날짜를 함께 돌려준다.
- **AC-4** 반복 일정을 "이 일정만"·"이후 모든 일정"·"모든 일정" 범위로 고치고 지울 수 있고, 결과는 결정 표와 같다.
- **AC-5** API 는 일정 만들기·읽기·고치기·지우기와 기간 조회를 제공하고, 잘못된 입력은 400, 없는 일정은 404 다. 조회 기간이 400일을 넘으면 400 이다.
