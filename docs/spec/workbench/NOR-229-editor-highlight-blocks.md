# NOR-229 — 편집기 코드 구문 강조와 커스텀 블록 메뉴

- 출처: 사용자 보고(2026-11-15). 문서를 편집할 때 코드 블록에 구문 강조가 없고, 블로그의 커스텀 블록(Markdoc 태그)을 넣는 메뉴가 없다.
- 원인: 편집기(CodeMirror)는 코드 블록 안의 언어를 파싱하지 않고 강조 스타일도 걸지 않는다. 미리보기는 코드를 `<pre data-language>` 글자로만 내보낸다.

## 결정

| 항목     | 결정                                                                                                                                                                        |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 언어     | `@codemirror/language-data` 로 코드 블록 언어를 필요할 때 불러온다. 편집기와 미리보기가 같은 파서를 쓴다                                                                    |
| 강조     | `@lezer/highlight` 의 `classHighlighter`(`tok-*` 클래스)를 쓴다. 색은 styles.css 가 테마별로 정한다. 인라인 스타일이 없어 CSP 를 바꾸지 않는다                              |
| 미리보기 | 서버 HTML 은 그대로 두고, 화면이 `pre[data-language]` 의 글자를 강조 구간으로 다시 그린다(글자는 `textContent` 로만 넣는다)                                                 |
| 블록     | 도구 막대의 "블록" 메뉴가 블로그 태그(callout·bookmark·github·youtube·video·figure·math·mathblock·bookquote) 틀을 커서 줄 아래 새 단락으로 넣고, 첫 자리 표시 값을 선택한다 |

## 수용 기준

- **AC-1** 편집기는 코드 블록 안의 언어를 파싱하고, 코드 토큰에 `tok-*` 강조 클래스를 붙인다.
- **AC-2** `highlightSegments(code, language)` 는 알려진 언어(별칭 포함, 예: `ts`·`csharp`·`rb`)를 강조 구간으로 나누고, 모르는 언어는 `null` 이다. 구간을 이어 붙이면 원래 코드와 같다.
- **AC-3** 블록 메뉴의 틀은 `bookquote` 를 빼고 모두 미리보기에서 경고 없이 렌더된다. `bookquote` 틀은 책 노트의 "인용 복사" 와 같은 모양이다.
- **AC-4** 블록을 넣으면 커서 줄 아래에 빈 줄로 띄운 새 단락이 생기고, 첫 자리 표시 값이 선택된다. 빈 줄에서는 그 자리에 넣는다.
