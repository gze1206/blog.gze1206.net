# NOR-218 — 블로그에 이미 있는 이미지를 참조한 글의 발행

- 출처: 운영에서 발견(2026-11-15, NOR-209 발행 상태). 블로그에서 가져온 글이 블로그에 이미 있는 이미지를 사이트 절대 경로(`/img/...`)로 참조하면 발행 검사가 "unresolved asset reference" 로 거절해, 가져온 글을 다시 발행할 수 없다.

## 수용 기준

- **AC-1** 발행 검사는 `/` 로 시작하는 안전한 사이트 경로(`//`·`..`·제어 문자 없음) 중, 발행 대상 블로그 저장소의 `public/` 아래에 일반 파일로 있는 것을 허용하고 참조를 바꾸지 않는다. 없는 경로나 안전하지 않은 경로는 지금처럼 거절한다.
- **AC-2** 검토·발행·발행 상태 조회가 모두 새로 받은 main 의 `public/` 을 기준으로 이 검사를 한다. 심볼릭 링크로 된 파일이나 상위 디렉터리는 받지 않는다.
