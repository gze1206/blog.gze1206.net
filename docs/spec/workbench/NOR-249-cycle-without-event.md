# NOR-249 — 불렛 유형 순환에서 일정 빼기

- 출처: 사용자 결정(2026-11-26). 빠른 캡처의 "일정" 은 실제 일정이 되는데(NOR-248), "유형" 버튼(Alt+→)은 ○ 불렛을 만들어 같은 "일정" 이 두 갈래로 갈린다.

## 결정

- 유형 순환은 할 일 → 메모 → 노트 → 할 일 만 돈다.
- 이미 있는 ○ 불렛에서 순환하면 할 일이 된다.
- 불렛을 일정으로 만드는 길은 "일정으로" 버튼 하나다. ○ 불렛은 예전 기록과 원본에서 직접 쓴 줄에만 남는다.

## 수용 기준

- **AC-1** 유형 순환은 할 일 → 메모 → 노트 → 할 일 순서이고 일정을 거치지 않는다. ○ 불렛에서 순환하면 할 일이 된다.
