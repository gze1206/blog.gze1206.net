# NOR-243 — 일정 화면과 일일 로그 연동

- 출처: 사용자 요청(2026-11-25). NOR-242 의 일정 API 위에 화면을 만든다.

## 결정

| 항목           | 결정                                                                                                                                            |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| 들어가는 길    | 사이드바의 "일정" 버튼. 일일 로그의 "이날의 일정" 에서도 그 날짜로 연다                                                                         |
| 월 달력        | 일요일부터 6주(42칸)를 보인다. 이전·다음 달과 "오늘" 버튼. 넓은 화면은 칸마다 일정 제목을 두 개까지, 좁은 화면은 점으로 개수를 보인다           |
| 고른 날        | 칸을 누르면 그날의 일정 목록을 달력 아래(넓은 화면은 오른쪽)에 보인다. 처음에는 오늘을 고른다                                                   |
| 목록 항목      | 종일/시각, 제목, 장소, 반복 표시(↻). 여러 날 일정은 시작~끝 날짜를 함께 보인다                                                                  |
| 만들기·고치기  | 같은 대화 상자를 쓴다. 제목, 종일, 날짜·끝 날짜, 시작·끝 시각, 장소, 반복(안 함·매일·매주·매월·매년, 간격, 주간 요일, 끝: 없음·날짜·횟수), 메모 |
| 반복 범위      | 반복 일정의 회차를 고치거나 지우면 "이 일정만·이후 모든 일정·모든 일정" 을 고른다. 한 번짜리 일정은 묻지 않는다                                 |
| 일일 로그 연동 | 일일 로그에 "이날의 일정" 을 두고 그날의 회차를 시각순으로 보인다. 항목이나 "일정 열기" 를 누르면 그 날짜의 일정 화면을 연다                    |
| 입력 크기      | 날짜·시각은 브라우저의 `date`·`time` 입력을 쓴다. 좁은 화면에서 버튼은 한 변 40px 이상이다                                                      |

## 수용 기준

- **AC-1** 월 달력은 일요일부터 시작하는 42칸이고, 이전·다음 달과 오늘로 옮길 수 있다. 칸은 그날 회차가 있으면 표시하고, 누르면 그날의 목록을 보인다.
- **AC-2** "새 일정" 으로 시각이 있는 매주 반복 일정을 만들면 고른 날 목록과 다음 주 칸에 나타난다.
- **AC-3** 반복 일정의 한 회차를 "이 일정만" 으로 고치면 그 회차만 바뀌고, "이후 모든 일정" 으로 지우면 그날부터 사라진다.
- **AC-4** 일일 로그의 "이날의 일정" 은 그날의 회차를 보이고, "일정 열기" 는 그 날짜를 고른 일정 화면을 연다.
- **AC-5** 390px 화면에서 일정 화면과 대화 상자가 가로로 넘치지 않는다.
- **AC-6** 대화 상자의 입력을 API 입력으로 바꾸는 변환은 종일이면 시각을 빼고, 반복 끝 방식에 따라 `until`·`count` 중 하나만 넣고, 빈 장소·메모를 정리한다. 달력 칸 계산은 일요일 시작 42칸이다.
