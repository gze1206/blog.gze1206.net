# NOR-240 — 데일리 노트는 일일 로그 화면으로 연다

- 출처: 사용자 제보(2026-11-24). 자동으로 만든 데일리 노트를 문서 목록에서 열면 원본 편집기가 열린다. 불렛마다 `<!-- wb:id=… -->` 주석이 그대로 보여 두 줄로 감기고, □·▣ 는 글자일 뿐이라 누를 수 없다.

## 현재

- 문서 목록의 일지(`kind: journal`)를 누르면 다른 문서처럼 Markdown 원본 편집기가 열린다.
- 불렛을 다루는 화면(일일 로그)은 `/day/날짜` 로만 지난 날을 열 수 있고, 앱 안에서 그리로 가는 길이 없다. 머리글은 날짜와 상관없이 "Today" 다.
- 원본 편집기의 라이브 프리뷰는 HTML 주석을 숨기지 않는다.

## 결정

| 항목            | 결정                                                                                                   |
| --------------- | ------------------------------------------------------------------------------------------------------ |
| 목록에서 열기   | 일지를 누르면 그 날짜의 일일 로그 화면을 연다                                                          |
| 원본 편집       | 일일 로그 화면에 "원본 편집" 버튼을 둔다. 그 날의 일지 문서가 있을 때만 보인다                         |
| 머리글          | 오늘이면 "Today", 아니면 "Daily log" 로 표시한다                                                       |
| 오늘로 돌아가기 | 사이드바의 "오늘의 로그" 는 지난 날을 보고 있어도 오늘로 돌아간다                                      |
| wb 주석         | 원본 편집기는 커서가 없는 줄의 `<!-- wb:… -->` 주석을 숨긴다. 다른 HTML 주석은 사용자가 쓴 글이라 둔다 |

## 수용 기준

- **AC-1** 문서 목록에서 일지를 누르면 그 날짜의 일일 로그 화면이 열리고, 머리글은 오늘이 아니면 "Daily log" 다.
- **AC-2** 일일 로그 화면의 "원본 편집" 은 그 날의 일지를 원본 편집기로 열고, 사이드바의 "오늘의 로그" 는 오늘 화면으로 돌아간다.
- **AC-3** 라이브 프리뷰는 커서가 없는 줄의 `<!-- wb:… -->` 주석과 앞 공백을 숨기고, 커서가 있는 줄과 다른 주석은 그대로 보인다.
