# NOR-212 — 책장으로 내보내기의 책 id 를 파일 이름으로 고정

- 출처: 사용자 보고(2026-11-15). 책 문서의 "책장으로 내보내기" 가 Document not found 만 낸다.

## 원인

화면과 서버가 책 id 를 문서 내용(`isbn13 ?? 제목 slug`)으로 계산했다. 등록한 뒤 ISBN 이나 제목을 고치면 id 가
파일 이름(`books/<id>.md`)과 어긋난다. 화면은 없는 파일을 찾고(ENOENT → Document not found), 서버는
"book id does not match document" 로 실패한다.

## 결정

책 id 는 **작업 공간의 파일 이름**이다. 등록할 때 한 번 정해지고, ISBN·제목을 고쳐도 바뀌지 않는다. 블로그의
책 JSON(`<id>.json`)과 표지(`<id>.<ext>`) 이름도 이 id 를 따르므로, 이미 내보낸 책과의 연결이 유지된다.

## 수용 기준

- **AC-1** 파일 이름과 다른 ISBN·제목을 가진 책 문서도 그 파일 이름으로 검토·확정할 수 있고, 결과는 `<파일 이름>.json` 이다.
- **AC-2** 책 편집 화면은 문서의 파일 이름(label)을 내보내기 id 로 쓴다.
