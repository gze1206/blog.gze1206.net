# NOR-226 — 워크벤치 타이포그래피도 Pretendard 로 통일

- 출처: NOR-224 후속. 블로그가 제목 명조를 빼고 Pretendard 로 통일했고, 워크벤치는 같은 시각 언어(NOR-203)를 쓴다.
- NOR-203 의 "제목 Noto Serif KR 600" 결정을 대체한다.

## 결정

| 항목 | 결정                                                               |
| ---- | ------------------------------------------------------------------ |
| 서체 | 제목·인용·편집기 머리글 모두 Pretendard. 명조 웹폰트는 싣지 않는다 |
| 굵기 | 제목은 700(`font-bold`), 자간은 블로그와 같은 -0.02em              |

## 수용 기준

- **AC-1** 워크벤치 화면 코드와 스타일은 `font-serif`·`--font-serif` 를 쓰지 않는다.
- **AC-2** 워크벤치는 `@fontsource/noto-serif-kr` 를 가져오지도, 의존성으로 두지도 않는다.
