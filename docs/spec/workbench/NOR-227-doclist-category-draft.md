# NOR-227 — 문서 목록: 카테고리 누락과 draft 글의 발행 상태 오표시

- 출처: 사용자 보고(2026-11-15). 카테고리가 있는 글이 "카테고리 없음" 으로 묶이고, `draft: true` 인 글이 발행된 글로 보인다.
- 원인 1: `GET /api/documents` 의 요약이 `category` 를 빼고 보낸다(NOR-221 은 저장소 계층만 고쳤다).
- 원인 2: 발행 상태에 draft 구분이 없다. `draft: true` 인 글도 블로그 파일과 같으면 `published` 가 된다.

## 결정

| 항목       | 결정                                                                                                                              |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------- |
| 카테고리   | 목록 요약과 문서 응답 모두 `category` 를 싣는다                                                                                   |
| draft 상태 | `draft: true` 인 글은 블로그와 같거나 블로그에 없으면 `draft` 다. 블로그와 다르면 `differs`, 검사 실패는 `invalid` 를 그대로 둔다 |
| 표시       | `draft` 는 "비공개 초안" 배지와 "공개 초안" 종류 이름으로 보인다. 편집기 머리는 "블로그에 보이지 않는 초안(draft)" 이다           |

## 수용 기준

- **AC-1** `GET /api/documents` 의 각 요약은 문서에 카테고리가 있으면 `category` 를 싣는다.
- **AC-2** 발행 상태 조회는 `draft: true` 인 공개 초안이 블로그 파일과 같거나 블로그에 없으면 `draft` 를 돌려준다.
- **AC-3** 문서 목록은 `draft` 상태의 글을 발행된 글로 부르지 않고 "비공개 초안" 배지를 붙인다.
