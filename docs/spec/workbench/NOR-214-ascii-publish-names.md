# NOR-214 — 발행 산출물·브랜치 이름을 ASCII 로

- 출처: 사용자 보고(2026-11-15). 책을 발행해도 PR 이 열리지 않는다.

## 원인

책 id 에 한글이 있으면(`니체의-초월자`) 산출물 이름(`book-니체의-초월자-….json`)과 브랜치(`content/book-니체의-초월자`)에도
한글이 들어간다. 릴레이(NOR-210)는 ledger·브랜치 안전을 위해 영문·숫자 이름만 받으므로 매분 건너뛴다.

## 수용 기준

- **AC-1** `publishRefKey(id)` 는 ASCII 소문자·숫자·하이픈만 돌려준다. 이미 그런 id 는 그대로 두고, 아닌 id 는 남는 ASCII 조각에 id 의 해시 10자를 붙인다. 같은 id 는 늘 같은 값이다.
- **AC-2** 책을 내보내면 산출물 이름은 `^[A-Za-z0-9][A-Za-z0-9._-]*\.json$`, 브랜치는 `^content/[A-Za-z0-9._-]+$` 이다.
- **AC-3** 릴레이는 bundle 을 매니페스트의 커밋으로 가져온다. 브랜치 이름에 다른 글자가 있어도 커밋이 맞으면 처리한다.
