# NOR-244 — 편집기 너비와 하위 목록 모양

- 출처: 사용자 제보(2026-11-26). "에디터 부분 너비가 제한되어 있는 것 같고, 목록의 하위 아이템 부분 스타일이 이상하네"

## 현재

- 편집기 본문(`.cm-content`)이 최대 52rem 이라 넓은 화면·나란히 보기에서 오른쪽이 비고 긴 줄이 일찍 감긴다.
- 미리보기는 모든 목록에 위아래 여백(`my-4`)을 주므로 하위 목록 앞뒤가 크게 벌어진다. 하위 목록도 같은 채운 점을 쓴다.
- 편집기는 하위 항목을 원본의 공백 두 칸만큼만 들여 보여 상위 항목과 거의 구별되지 않고, 감긴 줄은 줄 맨 앞에서 시작한다.

## 결정

| 항목          | 결정                                                                                                                           |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 편집기 너비   | 최대 너비를 없애 칸을 채운다                                                                                                   |
| 미리보기 목록 | 목록 안의 목록은 위아래 여백을 작게(0.25rem) 둔다. 하위 목록은 빈 원(○), 그 아래는 네모(■)로 표시해 깊이를 구별한다            |
| 편집기 목록   | 목록 항목 줄에 깊이 클래스를 붙여 깊이마다 들여 보이고, 감긴 줄은 표시 뒤에서 시작하게 한다. 커서가 없는 줄은 앞 공백을 숨긴다 |
| 원본          | 원본 글자는 바꾸지 않는다. 모양만 바꾼다                                                                                       |

## 수용 기준

- **AC-1** 넓은 화면에서 편집기 본문은 편집기 칸 너비를 채운다.
- **AC-2** 미리보기의 하위 목록은 위아래 여백이 0.25rem 이하이고, 깊이마다 목록 표시가 다르다.
- **AC-3** 라이브 프리뷰는 목록 항목 줄에 깊이 클래스(`cm-lp-li-1`·`cm-lp-li-2`…)를 붙이고, 커서가 없는 하위 항목 줄의 앞 공백을 숨긴다.
