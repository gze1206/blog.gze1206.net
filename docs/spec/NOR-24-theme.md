# NOR-24 — 베이스 테마와 토큰

## 목표

정적 콘텐츠 우선의 개인 개발 블로그에 가독성 중심의 전역 토큰과 다크/라이트 색 표면을 제공한다.

## 결정

- 본문 폭은 `max-w-3xl`, 본문 행간은 1.75를 유지한다.
- 브랜드 강조색은 접근성 포커스와 링크에 공통으로 쓰는 blue 계열로 제한한다.
- 전역 표면·텍스트·경계·muted·accent를 CSS 변수와 Tailwind 토큰으로 공개한다.
- 색상 모드는 `html.dark`로 적용한다. 시스템 매체 쿼리만으로 색을 바꾸지 않아 수동 선택이 일관되게 이긴다.

## 완료 조건

- 라이트/다크 표면과 본문 타이포그래피가 토큰으로 정의된다.
- 기존 컴포넌트의 `dark:` 유틸리티가 `html.dark`와 함께 동작한다.
- 전역 CSS의 다크 전용 스타일도 수동 모드와 충돌하지 않는다.
- `components.json`과 최소 Button 프리미티브로 Astro에서 쓸 shadcn/ui 경로를 설정한다.
