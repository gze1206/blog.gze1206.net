# 0019. 댓글 서버로 Comentario 를 OCI 에서 셀프호스팅

## 맥락 (Context)

블로그는 정적 사이트(Cloudflare Pages)라 댓글은 외부 서버가 필요하다. NOR-32 는 서버리스 Waline 을
계획했지만, 2026-11-12 재설계에서 워크벤치와 같은 OCI arm64 호스트(1 vCPU, 다른 서비스와 공유)에 셀프호스팅
하기로 했다. 후보는 Comentario 와 Artalk 였다. 요구 조건은 NOR-32 를 이어받는다: 로그인 없이 쓰기,
다크 모드 동기화, 한국어, 기본 스팸 방지.

## 검토한 대안 (Options)

2026-11-15 에 두 서버를 OCI 호스트에서 SQLite 로 띄워 실측했다.

| 항목             | Comentario 3.19.0                                    | Artalk 2.10.1                               |
| ---------------- | ---------------------------------------------------- | ------------------------------------------- |
| arm64 이미지     | 있음, 44MB                                           | 있음, 66MB                                  |
| 대기 메모리      | 29MiB                                                | 13MiB                                       |
| 이메일 없이 쓰기 | 된다. 이름만 필수로 둘 수 있다                       | 안 된다(`Email is required`, 업스트림 #572) |
| 익명 사전 승인   | `modAnonymous` 로 익명 댓글만 승인 대기에 둘 수 있다 | 전체 승인 대기 설정                         |
| 다크 모드        | `theme` 속성, 바꾸면 즉시 다시 그린다                | `darkMode` 설정                             |
| 한국어           | 있음                                                 | 있음                                        |
| 가져오기         | Commento·Disqus·WordPress                            | 여러 형식                                   |

## 결정 (Decision)

**Comentario 를 쓴다.** 이메일 없이 이름만 받는 익명 댓글을 포크나 업스트림 기여 없이 쓸 수 있고, 익명
댓글만 골라 승인 대기에 둘 수 있다. 메모리 차이(16MiB)는 이 호스트(가용 5GB)에서 제약이 아니다.

## 결과 (Consequences)

- 메일 발송(SMTP)을 두지 않는다. 승인 대기 댓글은 관리 화면에서 확인한다.
- 첫 가입자가 superuser 가 되고 기본값은 가입이 열려 있다. edge 에 붙이기 전에 루프백에서 계정을 만들고
  가입을 끈다([운영 절차](../operations/comments/oci.md)).
- `domainId` 를 지정한 요청은 Origin 이 달라도 받아들여졌다(실측). 익명 사전 승인이 스팸을 막고, 허용
  Origin 설정을 함께 건다.
- Artalk 의 이메일 선택 입력(#572)에는 기여하지 않는다.
